焊缝跟踪自动纠偏算法说明
==========================

一、问题和控制目标
------------------

车辆沿凸起焊缝前进。车上有线激光和 IMU：

  a：焊缝（目标轨迹）
  b：小车（被控制对象）
  c：线激光（测量焊缝在车体坐标系中的位置）

控制不是让车一次性打到某个角度，而是让两个误差逐渐回到零：

  e_s   -> 0       激光测到的焊缝横向位置回到目标位置
  e_psi -> 0       小车方位角回到焊缝方向

当 e_s 和 e_psi 都接近零时，激光中心就在焊缝上，同时小车的车头方向与焊缝方向一致。之后仍然允许小幅、慢速摆动，这是传感器噪声和地面扰动下的正常闭环行为。

本方案不额外使用 L*sin(e_psi) 修正项。L*sin(e_psi) 是“把某个前方参考点的误差换算到另一个参考点”时才需要的几何补偿；这里的横向误差直接定义在激光测量位置，航向误差直接由 IMU 给出，两个控制目标已经分别明确，不应重复补偿。

二、坐标和误差定义
------------------

1. 激光横向误差

从点云中提取凸起焊缝中心，得到测量位置 z（代码中根据设置可以使用点的 y 或 x 作为横向坐标）。设置目标位置 z_target，通常是激光中心线，定义：

  e_s_raw = signLaser * (z - z_target)

其中 signLaser 就是代码中的 steeringSign。它用于解决“激光坐标正方向”和“车辆物理右转方向”不一致的问题。代码随后对 e_s_raw 做一阶低通滤波，得到 e_s。

代码不是取最高的单个点，而是先用较低高度点估计背景平面，再选出高于背景的凸起区域，在焊缝峰值附近按高度加权求中心。这样比单点峰值更不容易被噪声、飞溅和缺点影响。

2. 航向误差

IMU 提供当前航向 yaw，设置焊缝方向参考 yaw_ref，定义：

  e_psi_raw = wrapToPi(yaw - yaw_ref)

wrapToPi 表示把角度折算到 [-pi, pi]。例如 +179 度和 -179 度只相差 2 度，不能被当成 358 度。代码对航向误差同样做低通滤波，得到 e_psi。

参考角有两种来源：

  - 手动输入焊缝方向的 IMU 角度；
  - 小车已经摆正并且激光在焊缝上时，点击“设为当前参考”，同时保存当前激光位置和当前 IMU 航向。

3. 角速度

IMU 的 gyroZ 是车体绕垂直轴的实际角速度，单位 rad/s。它先经过低通滤波，得到 r。gyroZ 不再由激光横向误差差分得到，因为差分会放大点云抖动。

三、控制律
----------

控制器输出车体角速度 omega，正值在本项目底盘中定义为物理右转：

  omega_cmd = signLaser  * K_s   * e_s
            + signHeading * K_psi * e_psi
            + signHeading * K_r   * r

参数含义：

  K_s       横向比例增益，对应界面中的横向 Kp
  K_psi     航向比例增益，对应界面中的航向 Kp
  K_r       陀螺阻尼增益，对应界面中的陀螺阻尼 Kd
  signLaser 横向坐标方向符号，对应 steeringSign
  signHeading IMU 航向正方向符号，对应 headingSign

横向项负责“焊缝偏到一边时转回去”；航向项负责“车头歪了时把车头摆正”；陀螺项负责“如果车正在转，就给反向阻尼，防止冲过头”。因此这是带航向反馈和角速度阻尼的二维 PD 控制，不使用激光误差的数值微分。

四、死区、限幅和柔性回归
------------------------

1. 小死区

当 |e_s| 小于 deadbandM 时令横向误差为 0；当 |e_psi| 小于 headingDeadbandRad 时令航向误差为 0。死区用于消除焊缝边缘噪声造成的高频左右切换。死区不能设置过大，否则车辆会长期偏离焊缝。

2. 角速度限幅

把 omega_cmd 限制在 [-maxAngularRadps, +maxAngularRadps]。这限制了最大转向强度，避免点云偶发错误直接给出过大的转向。

3. 角速度变化率限制

实际输出不是立即跳到 omega_cmd，而是每帧最多改变：

  delta_omega_max = maxAngularAccelerationRadps2 * dt

  omega(k) = omega(k-1) + clamp(omega_cmd - omega(k-1),
                                 -delta_omega_max, +delta_omega_max)

dt 使用实际激光帧之间的时间，限制在 5 ms 到 200 ms。这样可以防止“这一帧左转、下一帧马上满舵右转”，显著减小来回摆动。

4. 速度随误差降低

横向和航向误差越大，前进速度越低：

  q_s   = clamp(|e_s|   / maxLateralError, 0, 1)
  q_psi = clamp(|e_psi| / maxHeadingError, 0, 1)
  scale = clamp(1 - speedReductionGain * max(q_s, q_psi),
                minSpeedScale, 1)
  v_target = targetSpeed * scale

线速度也使用最大线加速度限制逐帧变化。这样车辆在歪得比较多时先慢下来，摆正后再恢复速度。

五、焊缝检测和安全停车
----------------------

每帧点云处理流程：

  1. 按横向范围筛选点并按横向坐标排序；
  2. 用较低高度点估计背景高度；
  3. 找到相对背景足够高的凸起峰值；
  4. 在峰值附近的窗口内按凸起高度加权求焊缝中心；
  5. 对中心位置低通滤波后计算控制量。

以下情况立即输出线速度 0、角速度 0，并退出自动纠偏：

  - 激光有效点太少；
  - 没有达到凸起阈值；
  - 焊缝候选点数量或置信度不足；
  - 激光数据超过 profileTimeoutMs 未更新；
  - IMU 数据超过 imuTimeoutMs 未更新；
  - |e_s| 超过 maxLateralErrorM；
  - |e_psi| 超过 maxHeadingErrorRad。

这几项是失效保护，不是控制器的正常纠偏动作。传感器恢复后需要重新启动自动纠偏，避免故障恢复瞬间突然运动。

六、如何判断向左转还是向右转
------------------------------

先把车辆放在焊缝右侧或左侧，低速运行，暂时只保留横向 Kp，航向 Kp 和阻尼设为 0。观察给出的角速度和车辆实际动作：

  - 若焊缝在激光中心右侧，车辆应该右转；
  - 若焊缝在激光中心左侧，车辆应该左转。

如果方向相反，只翻转 steeringSign（+1 改 -1，或 -1 改 +1），不要同时修改 Kp 符号。

然后把车辆摆正但故意让车头偏一个小角度，只保留航向 Kp，观察：

  - 车头偏向右侧时，应产生能把车头转回焊缝方向的角速度；
  - 车头偏向左侧时，角速度应反向。

如果 IMU 的 yaw 正方向与底盘定义相反，翻转 headingSign。激光坐标符号和 IMU 符号必须分别标定，不能用一个符号同时代替两个符号。

七、建议调参顺序
----------------

1. 车辆架空或极低速确认底盘正角速度确实是右转。
2. 标定 steeringSign：只调横向 Kp，确认偏右向右修、偏左向左修。
3. 标定 headingSign：只调航向 Kp，确认车头能回到焊缝方向。
4. 把目标速度降到很低，横向 Kp 从小到大增加，直到能回到焊缝但不明显摆动。
5. 增加航向 Kp，使车头方向跟随焊缝；航向 Kp 过大时会左右摆动。
6. 增加陀螺阻尼 Kd，直到转向停止时不再明显冲过头。阻尼过大则反应迟钝。
7. 设置合适的死区、最大角速度和最大角加速度。摆动快时优先减小最大角加速度、降低速度或增大少量死区，不要先盲目增加 Kp。
8. 最后逐步提高目标速度，并确认激光、IMU 的超时停车仍然有效。

八、现场判断标准
----------------

稳定跟踪时应看到：

  - 激光横向误差围绕 0 小幅、慢速变化；
  - 航向误差围绕 0 小幅变化；
  - 角速度没有持续打满，也没有快速左右交替；
  - 焊缝置信度稳定，丢线时车辆停车；
  - 误差变大时速度自动降低，误差变小时速度恢复。

若车辆左右来回摆动，按以下顺序处理：降低目标速度 -> 减小横向 Kp 或航向 Kp -> 限制最大角速度变化率 -> 增加陀螺阻尼 -> 最后再微调死区。若车辆始终向错误方向转，先检查 steeringSign/headingSign 和 IMU、激光坐标轴定义，不要用增益大小掩盖符号错误。
