焊缝跟踪纠偏算法说明（优化版）
================================

版本目标
--------

车辆沿凸起焊缝前进，线激光提供焊缝横向位置，IMU 提供 yaw 和 gyroZ。
控制器输出车体角速度 omega_cmd，单位 rad/s；本项目底盘约定 omega_cmd > 0
表示物理右转。控制目标是：

  eL    -> 0    激光目标点回到焊缝中心
  e_psi -> 0    车头回到焊缝方向

点云中心提取、降速、角速度限幅、角速度变化率限制以及丢线/超时/超差停车
逻辑继续保留。

一、统一符号约定
----------------

所有进入控制律的正误差，都定义为“当前需要向右修正”；负误差表示需要向左
修正。三个传感器符号分别标定，不能混用：

  steeringSign：激光横向坐标符号，取 +1 或 -1
  headingSign ：IMU yaw 误差符号，取 +1 或 -1
  gyroSign    ：IMU gyroZ 角速度符号，取 +1 或 -1

底盘正角速度已经由 differential_mixer.cpp 明确定义为右转。

二、误差定义
------------

1. 激光/车体基准横向误差

点云提取出的凸起焊缝中心为 z，目标中心为 z_target：

  e_s_raw = steeringSign * (z - z_target)                 (1)

steeringSign 只在式 (1) 使用一次。后面的横向比例项不能再乘
steeringSign，否则会出现 sign 的重复使用或文档、代码不一致。

2. 航向误差

  e_psi_raw = headingSign * wrapToPi(yaw - yaw_reference) (2)

wrapToPi 把角度限制到 [-pi, pi]，避免 +179 deg 到 -179 deg 被误认为
358 deg。headingSign 只在式 (2) 使用一次，后面的航向比例项不再乘它。

3. 前瞻误差

激光测量平面位于车体控制点前方 L 米时：

  eL_raw = e_s_raw + L * sin(e_psi)                       (3)

默认 L = 0.30 m，可在参数面板中按实际安装距离修改。式 (3) 的几何意义是：
车体控制点可以暂时有横向偏差，但前方激光目标点应落在焊缝中心。若初始状态
满足：

  e_s(0) = -L * sin(e_psi(0))

则 eL(0) = 0，启动瞬间激光目标点就在焊缝上。

重要的现场确认：如果相机 SDK 输出的 z-z_target 本身已经是“激光测量平面处
的焊缝相对激光中心偏差”，这个量本身就是 eL，不是车体控制点的 e_s。此时
必须把面板中的 L 设为 0，否则会把 L*sin(e_psi) 重复计算。当前代码按任务书
把默认值设为 0.30 m，但应通过一次静态几何试验确认数据含义。

三、按实际采样周期进行低通滤波
------------------------------

eL、e_psi 和 gyroZ 分别做一阶低通。滤波系数不再假定固定帧率，而是按实际
采样周期 dt 计算：

  alpha = 1 - exp(-2*pi*f_c*dt)                            (4)
  x_f(k) = x_f(k-1) + alpha * (x_raw(k) - x_f(k-1))        (5)

航向滤波使用环绕角度差。默认截止频率：

  lateralFilterCutoffHz = 4 Hz
  headingFilterCutoffHz = 4 Hz
  gyroFilterCutoffHz    = 8 Hz

三项截止频率均可在参数面板直接修改并保存。

滤波截止频率应大致为实测闭环带宽的 5 到 10 倍。没有实车频谱前，默认值只是
保守起点；应记录 eL、e_psi 和 omega_cmd 后再确定。截止频率太低会造成相位
滞后和慢速极限环，太高则会让点云和 IMU 噪声直接进入转向命令。

第一帧直接用当前有效测量初始化滤波器，避免从 0 缓慢爬升而暂时低估真实偏差。

四、连续死区
------------

对滤波后的 eL 和 e_psi 使用连续死区：

                 0,                              |e| <= d
  deadband(e) = sign(e) * (|e| - d),             |e| > d     (6)

横向死区宽度是 deadbandM，航向死区宽度是 headingDeadbandRad。连续死区在
边界处不会突然从 0 跳到完整误差，可减少左右快速切换。

记死区后的误差为 eL_d、e_psi_d。控制律和速度缩放都使用这两个值，避免进入
死区后控制归零、但速度缩放仍按原误差变化而产生轻微加减速振荡。

五、控制律
----------

gyroZ 先低通，再用独立 gyroSign 换算到底盘“右转为正”的角速度：

  r_chassis = gyroSign * LPF(gyroZ)                        (7)

横向积分状态：

  I(k) = clamp(I(k-1) + eL_d*dt, -0.30, +0.30)             (8)

最终未限幅角速度：

  omega_raw = Ks*eL_d + Ki*I + K_psi*e_psi_d - Kr*r_chassis (9)

参数对应关系：

  Ks    = proportionalGain，面板“横向比例 Kp”
  Ki    = integralGain，面板“横向积分 Ki”，默认 0（关闭）
  K_psi = headingGain，面板“航向比例 Kp”
  Kr    = derivativeGain，面板“陀螺阻尼 Kd”

式 (9) 的陀螺项必须是负号。车体正在向右转时 r_chassis > 0，阻尼项给出左转
命令；车体正在向左转时则相反。因此 Kr > 0 始终消耗转动趋势，不是正反馈。

积分仅用于消除安装偏置和 z_target 标定偏差。默认 Ki=0，不完成 P、航向和阻尼
调试前不要启用。积分限制为 +/-0.30 m*s；当角速度已经饱和且当前误差还会推动
积分继续朝饱和方向增长时，暂停积分，防止 wind-up。

六、限幅、变化率限制和柔性降速
--------------------------------

1. 角速度限幅：

  omega_target = clamp(omega_raw,
                       -maxAngularRadps, +maxAngularRadps) (10)

2. 按实际激光帧周期限制角速度变化率：

  delta_omega_max = maxAngularAccelerationRadps2 * dt
  omega_cmd(k) = omega_cmd(k-1)
               + clamp(omega_target - omega_cmd(k-1),
                       -delta_omega_max, +delta_omega_max) (11)

实际 dt 被限制在 5 ms 到 200 ms，避免时间戳异常造成一步跳变。

3. 速度缩放使用死区后的误差：

  qL   = clamp(|eL_d|    / maxLateralErrorM, 0, 1)
  qPsi = clamp(|e_psi_d| / maxHeadingErrorRad, 0, 1)
  scale = clamp(1 - speedReductionGain*max(qL, qPsi),
                minSpeedScale, 1)                          (12)
  v_target = targetSpeedMps * scale

线速度仍受 maxLinearAccelerationMps2 限制。偏差大时先降速，误差进入死区后平滑
恢复目标速度。

七、点云焊缝中心提取
--------------------

每帧执行：

  1. 按 lateralMinM 到 lateralMaxM 筛选点并按横向坐标排序；
  2. 用较低的 60% 高度点估计背景平面；
  3. 找最高凸起并检查 prominenceThresholdM；
  4. 在 contourHalfWidthM 窗口内保留足够高的凸起点；
  5. 按相对凸起高度加权求焊缝中心 z；
  6. 计算式 (1) 到式 (9)。

该部分不依赖单个最高点，可降低点云噪声、飞溅和局部缺点的影响。

八、失效保护（保持原逻辑）
--------------------------

以下情况立即输出 v=0、omega=0，并退出自动纠偏：

  - 有效点少于要求；
  - 未检测到足够高的凸起；
  - 候选点数量或置信度不足；
  - 激光数据超过 profileTimeoutMs 未更新；
  - IMU 数据超过 imuTimeoutMs 未更新；
  - |eL| 超过 maxLateralErrorM；
  - |e_psi| 超过 maxHeadingErrorRad。

传感器恢复后不会自动重新运动，需要人工再次启动自动纠偏。

九、三个符号的现场标定
----------------------

1. steeringSign

将 Ki、K_psi、Kr 临时设为 0，只保留很小的 Ks 和低速。焊缝在激光中心右侧时
车辆应向右修，焊缝在左侧时应向左修。方向相反时只翻转 steeringSign。

2. headingSign

将 Ks、Ki、Kr 临时设为 0，只保留较小 K_psi。车头偏离参考方向后，输出必须使
车头回到参考方向；方向相反时只翻转 headingSign。

3. gyroSign

将 Ks、Ki、K_psi 设为 0，只保留 Kr=0.1 起步。外力使车体向右转时，控制输出
必须给左转命令，向左转时必须给右转命令。若输出助推当前旋转，立即停车并翻转
gyroSign。Kr 项不允许通过负增益修方向，Kr 始终保持非负。

十、推荐调试顺序
----------------

  1. 低速确认底盘 omega_cmd > 0 确实物理右转。
  2. L 暂设 0，Ki=0，K_psi=0，Kr=0，标定 steeringSign。
  3. Ks=0，Ki=0，Kr=0，标定 headingSign。
  4. Ks=0，Ki=0，K_psi=0，从小到大调 Kr 并标定 gyroSign，确认是阻尼。
  5. 根据激光测量量的物理含义设置 L；未知时先测安装距离 0.30 m，并检查是否
     存在重复前瞻。验证 e_s(0)=-L*sin(e_psi(0)) 时 eL(0) 接近 0。
  6. 低速逐步增加 Ks，使 eL 能回零但不快速左右摆动。
  7. 增加 K_psi，使车头方向稳定回到焊缝方向。
  8. 增加 Kr，直到过冲明显衰减；过大则转向迟钝。
  9. 只有存在稳定静差时才从很小的 Ki 开始增加，并观察积分是否长期顶到限幅。
 10. 记录误差频谱，调整截止频率，再逐步提高行驶速度。

十一、验收项目
--------------

  - 翻转 steeringSign 后，仅 Ks 产生的转向方向必须翻转；代码中该符号只出现于
    e_s 定义，不在比例控制项再次出现。
  - 仅保留 Kr 时，输出角速度必须与 r_chassis 方向相反。
  - 设置实际 L 后，eL 长时间稳定在 +/-10 mm 内；若 z 已是激光平面误差，则
    L=0 时应优于 L=0.30 m。
  - Ki 启用后，人工加入 +/-50 mm 标定偏差时静差能够逐渐消除，积分不超过
    +/-0.30 m*s，输出没有阶跃。
  - 死区内 eL_d、e_psi_d 和速度缩放同时归零，不发生进入死区瞬间的速度跳变。
  - 丢线、激光超时、IMU 超时、横向超差和航向超差均能停车并退出。

以上验收必须在实车低速、具备急停条件时完成。静态代码检查只能证明符号和限幅
逻辑一致，不能替代激光坐标、IMU 轴向和安装距离的现场标定。
