触摸屏点击切换控制模式 - 实现完成
=====================================

## 问题根因
远程桌面软件（RustDesk/ToDesk）在平板触摸时发送瞬时点击（0-3ms），不传输手指持续按压状态。
原有的"按住移动"逻辑无法在触摸屏上工作。

## 解决方案
实现短按切换模式：
- **短按 (<250ms)**: 切换运动开关
  * 第一次点击：启动运动并保持
  * 再次点击同按钮：停止运动
  * 点击不同按钮：切换方向
  
- **长按 (≥250ms, 鼠标)**: 保留原有行为
  * 按住时运动，松开停止
  * 3秒长按锁定（仅前进/后退）

## 测试要点

### 平板触摸测试
1. 短按前进 → 小车持续前进
2. 再次短按前进 → 小车停止
3. 短按左转 → 小车停止前进，开始左转
4. 短按右转 → 小车停止左转，开始右转
5. 再次短按右转 → 小车停止

### 鼠标测试（保持原行为）
1. 按住前进 → 小车前进
2. 松开前进 → 小车停止
3. 长按前进3秒 → 锁定（松开仍前进）
4. 点击其他方向 → 解除锁定并切换方向

### 安全测试
1. Toggle运动中按急停 → 立即停止
2. Toggle运动中断开连接 → 立即停止
3. Toggle运动中窗口失焦 → 立即停止
4. Toggle运动中驱动器故障 → 立即停止
