# PA1664 上位机/下位机部署系统 - 使用指南

## 🚀 快速开始

### 1. 开发机：编译和打包

进入 startup_deploy 目录，双击：

`
【开发机】编译打包工具.cmd
`

**两种模式**：

- **完整构建（FULL BUILD）** - 首次使用或依赖变化时
  - 编译两个 EXE 文件
  - 收集所有依赖（Qt、OpenCV、SDK DLL）
  - 耗时约 5-10 分钟
  
- **快速构建（QUICK BUILD）** - 日常开发迭代
  - 仅编译 EXE 文件并更新到 app 文件夹
  - 跳过依赖收集
  - 耗时约 1-2 分钟

**首次使用请选择 [1] FULL BUILD**

---

### 2. 小车电脑：部署下位机程序

#### 2.1 复制文件
将整个 obot_host 文件夹复制到小车电脑任意位置（例如 D:\robot_host）

#### 2.2 配置网络
编辑 obot_host\config\host.psd1：

`powershell
@{
    TcpCommandPort = 43100
    UdpRealtimePort = 43101
    UdpMediaPort = 43102
    TcpBulkPort = 43103
}
`

#### 2.3 启动程序
双击 启动小车程序.cmd

**首次运行会自动安装开机自启动**（需要管理员权限）

---

### 3. 操作电脑：部署上位机程序

#### 3.1 复制文件
将整个 operator_workbench 文件夹复制到操作电脑任意位置

#### 3.2 配置小车 IP
编辑 operator_workbench\config\workbench.psd1：

`powershell
@{
    RobotHostIP = "192.168.1.100"  # 改成小车电脑的实际 IP
    TcpCommandPort = 43100
    UdpRealtimePort = 43101
    UdpMediaPort = 43102
    TcpBulkPort = 43103
}
`

#### 3.3 启动程序
双击 启动操作界面.cmd

## 🔧 高级用法

### 命令行编译（跳过交互菜单）

#### 完整构建：
`powershell
powershell -ExecutionPolicy Bypass -File ..\build-all.ps1
`

#### 快速构建：
`powershell
powershell -ExecutionPolicy Bypass -File ..\build-all.ps1 -QuickMode
`

#### 指定 Qt 路径：
`powershell
powershell -ExecutionPolicy Bypass -File ..\build-all.ps1 -QtPath "D:\Qt\6.8.3\msvc2022_64"
`

---

### 开机自启动管理

#### 安装开机自启动（管理员权限）：
- 小车电脑：运行 obot_host\InstallAutoStart.ps1
- 操作电脑：运行 operator_workbench\InstallAutoStart.ps1

#### 卸载开机自启动：
- 运行对应的 UninstallAutoStart.ps1

## ⚠️ 常见问题

### 1. 编译失败：找不到 qmake
**解决方案**：
- 安装 Qt 6.8.x MSVC 2022 64-bit
- 或在编译时指定 Qt 路径：.\build-all.ps1 -QtPath "D:\Qt\6.8.3\msvc2022_64"

### 2. 编译失败：找不到 nmake
**解决方案**：
1. 打开 "x64 Native Tools Command Prompt for VS 2022"
2. 切换到项目目录
3. 运行：powershell -ExecutionPolicy Bypass -File .\build-all.ps1

### 3. 快速构建提示 "app not found"
**原因**：首次编译必须使用完整构建

**解决方案**：运行一次完整构建（选项 [1]）

### 4. 连接失败
**检查项**：
- 小车程序是否正常运行
- IP 地址是否正确配置
- 防火墙是否允许端口 43100-43103
- 两台电脑是否在同一网络

## 🎯 工作流程示例

### 首次部署
1. 开发机：运行 【开发机】编译打包工具.cmd → 选择 [1] FULL BUILD
2. 小车电脑：复制 obot_host → 配置 IP → 双击启动 → 安装自启动
3. 操作电脑：复制 operator_workbench → 配置小车 IP → 双击启动
4. 测试连接和功能

### 日常开发
1. 修改代码
2. 开发机：运行 【开发机】编译打包工具.cmd → 选择 [2] QUICK BUILD
3. 仅更新对应电脑的 EXE 文件（app 文件夹中）
4. 重启程序测试

### 依赖变化时（添加新库、升级 Qt 等）
1. 开发机：运行 【开发机】编译打包工具.cmd → 选择 [1] FULL BUILD
2. 重新复制整个 obot_host 或 operator_workbench 文件夹到目标电脑
3. 重启程序
