# IP 连接方式详解

## 📡 连接方式对比

### ✅ 方式1: 同段局域网（最简单，最常用）
**示例:** 
- Robot Host: 192.168.1.100
- Workbench:  192.168.1.200

**优点:**
- 无需路由器配置
- 延迟最低（<1ms）
- 不需要额外网络设置
- 直接互相访问

**适用场景:** 工厂车间、实验室、办公室内部

---

### ✅ 方式2: 不同段局域网（需要路由）
**示例:**
- Robot Host: 192.168.1.100
- Workbench:  192.168.50.200

**要求:**
- 需要路由器支持跨网段路由
- 两个网段之间有路由表
- 防火墙允许端口 43100-43103

**配置检查:**
\\\powershell
# 从 Workbench PC 测试能否访问 Robot Host
ping 192.168.1.100

# 测试端口连通性
Test-NetConnection -ComputerName 192.168.1.100 -Port 43100
\\\

**适用场景:** 多个车间通过中心交换机连接

---

### ✅ 方式3: 直连（点对点）
**说明:** 两台电脑用网线直接连接

**配置步骤:**
1. 用网线连接两台电脑的网口
2. 手动设置静态IP（Windows会自动分配169.254.x.x）

**手动配置示例:**
- Robot Host: 设置为 192.168.100.1，子网掩码 255.255.255.0
- Workbench:  设置为 192.168.100.2，子网掩码 255.255.255.0

**优点:**
- 不需要交换机/路由器
- 专用连接，无干扰
- 最高带宽

**适用场景:** 临时测试、移动机器人

---

### ✅ 方式4: WiFi 连接
**说明:** 通过WiFi路由器连接

**要求:**
- 两台设备连接到同一WiFi网络
- 路由器支持 AP隔离关闭（某些公共WiFi会隔离设备）

**检查WiFi是否支持:**
\\\powershell
# 在 Workbench PC 上测试
ping [Robot_Host_IP]
\\\
如果 ping 不通，可能是路由器启用了 AP 隔离

**适用场景:** 无法布线的环境

---

### ✅ 方式5: VPN/远程连接
**说明:** 通过互联网远程连接

**方式A - 端口转发:**
1. 在机器人端路由器配置端口转发 43100-43103
2. Workbench 配置为路由器的公网IP
3. 需要路由器有公网IP或DDNS

**方式B - VPN:**
1. 建立 VPN 连接（如 ZeroTier, WireGuard, OpenVPN）
2. VPN 会分配虚拟IP（如 10.147.x.x）
3. Workbench 连接到 Robot Host 的虚拟IP

**优点:** 可以跨越互联网控制
**缺点:** 延迟较高，依赖网络稳定性

**适用场景:** 远程调试、多地部署

---

## 🔍 连接测试步骤

### 步骤1: 测试基本连通性
\\\powershell
# 在 Workbench PC 运行
ping [Robot_Host_IP]
\\\
- ✅ 有响应 → 网络可达
- ❌ 请求超时 → 检查网络或防火墙

### 步骤2: 测试端口连通性
\\\powershell
# 在 Workbench PC 运行
Test-NetConnection -ComputerName [Robot_Host_IP] -Port 43100
\\\
- ✅ TcpTestSucceeded: True → 端口开放
- ❌ TcpTestSucceeded: False → 检查防火墙或服务未启动

### 步骤3: 查看防火墙规则
\\\powershell
# 在 Robot Host PC 运行
netsh advfirewall firewall show rule name=all | Select-String "43100"
\\\

## 🛡️ 防火墙配置

### Windows 防火墙 - 允许端口（Robot Host PC）
\\\powershell
# 允许 TCP 端口 43100-43103
New-NetFirewallRule -DisplayName "PA1664 Robot Host" -Direction Inbound -Protocol TCP -LocalPort 43100-43103 -Action Allow
\\\

### 临时关闭防火墙测试（不推荐生产环境）
\\\powershell
# 仅用于测试
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False
# 测试后记得恢复
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True
\\\

## 💡 推荐配置

### 工厂/实验室环境（推荐）
- 使用**同段局域网**
- 有线连接（千兆网卡）
- 配置静态IP避免DHCP变化

### 移动机器人/临时测试
- 使用**直连**或**WiFi**
- 配置静态IP

### 远程维护
- 使用 **VPN** 方案
- 推荐 ZeroTier（简单易用）或 WireGuard（高性能）
