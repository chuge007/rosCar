以下为初版流程记录；最新断点上限和模式切换以本节为准。

自动纠偏输入已切换到当前 HFR 相机的 ImageMode=7。驱动已有逐轮廓回调；
设备控制器在预览抽样之前提取最新完整扫描行，保留全部点和无效点槽位。
每 33 ms 最多发布一次最新扫描，避免把高频轮廓堆入控制线程。
这不是轮廓截图识别，也不从灰度图绘制一条轮廓后再检测。

`ProfileWeldDetector` 使用 SDK X/Z 坐标：

1. 排除非有限值、Z<=0 和逆序 X 点，保留原始扫描索引。
2. 用相邻高度差的 MAD 估计噪声；用两端各 10% 的母材建立倾斜基线。
3. 迭代拟合母材，排除凸起和向下异常；结合两端母材残差估计背景起伏。
4. 高于基线 5 倍噪声的点建立候选，3 倍噪声扩展边界。允许 2～8 个点的短断点，
   但真实支撑不少于 70%，单个断点不得超过候选宽度 20%。
5. 两边须有母材支撑，至少 3 个高阈值点，宽度至少 6 点且符合配置最小比例。
   不要求顶部平直，不要求灰度暗缺口。连续山峰和悬空凸起段使用同一规则。
6. 以凸起面积与历史位置关联选候选；相近强度的多个候选判为歧义。
   中心取真实左右边界中点，避免不对称峰值变化拉动中心。
7. 初始连续三帧确认后进入原有首段采集、返回和闭环跟踪。

SDK 点结果不参与原图暗缺口/OpenCV 冲突仲裁。图像检测代码保留供独立测试，
实时纠偏已取消原始图像信号连接，避免两种输入交替覆盖跟踪身份。
日志模式 `sdk_profile_height`，结构日志 `laser_profile_detection` 提供原始扫描
边界索引、噪声、基线、关联拒绝信息。旧结构的 `*Px` 字段对该来源表示扫描索引，
不是真实图像像素。横向米制控制仍沿用配置的扫描跨度；SDK 高度单位不用于推算
横向标定，正 Z 为凸起方向。其余相机型号的模式、方向和单位需要匹配设备标定。

当前限制：需要两侧有效母材；焊道占据扫描端部、全宽、母材显著弯曲或高度低于
背景起伏时，不保证有效定位，不会靠长距离补点制造观测。保留既有超时/边界保护。
相机切到轮廓输出后，原始灰度图预览不保证同时有新帧，轮廓预览仍走独立显示链路。
