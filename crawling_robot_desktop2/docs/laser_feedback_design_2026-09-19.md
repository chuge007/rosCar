本轮采用实时图像前视回中为主、几何轨迹航向为辅的连续反馈控制。先解决观测目标和时间链路，再调整控制。一次拟合得到的角度不能直接当成需要一次执行完的车体转角；目标是在持续前进中，每次依据当前可见焊缝重新计算转向。

## 观测模型与算法选择

设车轴为原点，前进方向为 x、车体右侧为 y；激光扫描平面在车前 `L`，扫描处焊缝中心横向误差为 `e`。左右轮保持正向滚动时：

`v_left = v + omega * B / 2`，`v_right = v - omega * B / 2`。

`e` 是车头前方扫描截面的误差，不是车轴处横向误差。若局部直线在车体系的斜率为 `m`，其理想运动关系为：

`de/dt = v*m - omega*(L + e*m)`。

| 方法 | 本项目适用性 |
| --- | --- |
| 把扫描误差当车轴横移做 P 控制 | 忽略前视几何，容易滞后和过冲，不采用 |
| 实时图像前视曲率反馈 | 对局部航向估计依赖小，作为当前主反馈 |
| 精确扫描模型反馈线性化 | 理想情况下可消除大部分过冲，但依赖准确 L、尺度、局部斜率和时延；当前不能直接保证这些条件 |
| MPC | 可以显式处理边界及轮速约束，但同样依赖可靠状态/模型；在误定位和标定尚未解决时更换求解器不能解决主要故障 |

实际主反馈为 `omega_center = gain * confidence * v * 2*e_pred / (L^2 + e_pred^2)`。`e_pred` 用短时滤波误差与受限变化率预测，接近中心时提前收回转向。轨迹拟合只提供低权、按年龄衰减的航向项；离中心较远时抑制与实时回中相反的航向项。两项加轮速 yaw 阻尼后统一做曲率、内外轮比例与角加速度限制。

离线脚本 `tools/research_laser_feedback.py` 已重新执行：每种方法 24 个理想平面场景，速度 5/30/100 mm/s，初始横移 ±50 mm，延迟 30/150 ms、初始航向 0/4°。前视法最坏越中约 15.46 mm，精确扫描模型约 0.059 mm，错误车轴 P 法约 168.16 mm。精确模型使用理想真值斜率，这是其优势前提，不能把该结果当作真实算法或设备验收；这些模型都未包含目标误识别、JPEG 伪影、轮子打滑和完整生产控制器。

## 已修改的数据与控制链

1. 沿广域主激光基线提取暗缺口，同时提取偏离基线的连续几何轮廓。短小暗洞先填补。初始轮廓明显宽于小暗洞时可作为主候选；已建立身份后，高置信双边缺口不被低置信轮廓随意覆盖。
2. 双边缺口连续 3 帧确认；凸起轮廓连续 5 帧、位置/宽度一致并有足够支撑才可建立或重新确认低权身份。普通轮廓辅助帧仅更新实时位置关联，不反复重写身份宽度、主线范围；稳定轮廓不再因长期没有暗缺口而周期性失效。
3. 单边缺口用已确认的全图宽度推断，只有限更新中心。修复旧局部宽度被 sampleStep 重复缩小的问题。
4. 原始图双边实测才进入连续几何轨迹；轮廓和单边推断仍可进入诊断图，但不伪装成双边拟合证据。拼接轨迹按同一车体坐标变换，受样本跨度、RMS、年龄和外推距离约束。
5. 删除中心角速度内部的第二层斜坡，统一在融合输出后平滑。小误差反向需两个不同的相机观测帧，重复轮速回调不增加确认数；普通分段切换不清空反向确认记忆。
6. 边界余量按整个缺口包络计算，并加入受限的向外运动预测。预测回中不能提前放松保护；单边/轮廓只在新鲜且有可信度时参与有限边界回中，陈旧预测不能强制满权转向。
7. 正常定位保持设置速度，短时失检有 500 ms 缓冲；持续失检平滑降级，边界和观测保护取最小值，不多次相乘。父激光线可见不能被当成焊缝已经找回。
8. 纠偏对象及其定时器运行于独立线程。界面设置/启停、轮速与图像输入、预览和日志均经队列；界面和同步日志写盘不再直接阻塞纠偏线程。启动握手期间抑制手动零速插入。
9. 根据用户确认的安装关系，将电机转数/车轮转数默认设为 36；旧配置版本的 1/100 占位值迁移到 36，当前版本显式设定和其他自定义比例保留。

## 诊断与验证

原图 PNG、frames.jsonl 和控制 JSON 保留帧号关联。日志区分双边实测、轮廓、单边推断和沿用；新增缺口包络余量、实际检测先验、凸起轮廓主候选标记、速度监督与换向确认信息。界面用紫色标记轮廓辅助，避免误报成绿色双边实测。

当前工作区缺少用户此前引用的 `release/logs/frames.jsonl` 及对应原帧，因此本轮不能重新跑完整现场原图回放。之前保留的轮廓实验结果是候选覆盖率，不是人工标注准确率。

## 尚需实测确认的边界

横向全幅 200 mm 和前视距离 250 mm 仍是标称值，日志继续标记 `geometry_source=assumed`。车头相机安装极性、实际物理跨度、前视距离、轮距、轮子打滑和电机反馈单位需要独立核对。不能从二维图片本身唯一恢复精确车体转角。

当前所谓轮廓是同一相机原图提取的二维脊线，拼接轨迹也来自这些图像；没有把 SDK 独立三维 profile 数据伪称为已融合。相机当前提供 JPEG 时，归档 PNG 只保证解码后图像无损保存。

RS485 写轮速仍为约 100 ms 周期，未在不知道总线余量时强行加频；独立纠偏线程也不等于硬实时。现场尚未证明整个闭环稳定或焊缝绝不出扫描范围，下一次日志应首先验证主目标框是否正确、观测到命令的时间间隔、包络余量及有符号误差是否持续收敛。
