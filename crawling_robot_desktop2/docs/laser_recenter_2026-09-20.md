## 代码行为

- 保留 SDK 原尺寸图像的主基线双边定位、连续帧确认、位置和宽度关联。本次样本已成功定位，不放宽门限来掩盖状态机误停。
- 正常视野内完成初始直行采集和返程，再用实时中心误差、短时趋势预测、轮速角速度阻尼和滚动路径方向闭环前进。不加积分项，避免限幅期间积累转向量；角加速度限制、中心死区和反向确认抑制快速摆动。
- 包络余量进入 25% 时提前回中，恢复到 29% 才释放边界优先。最低回中差速随余量连续增强，可超出柔性曲率限制，仍保持车速、最大角速度和内外轮比例限制。
- 宽焊道在扫描中心附近、两侧预测余量差不超过视场 2% 时，不强制向任意一侧转向，防止两侧都接近阈值时左右交替纠偏。
- 20 ms 控制心跳使用最新图像中心和有效期内的轮速反馈更新转向，不等待下一次较慢的电机回复；里程仍仅在收到实际反馈时积分。收到无效轮速反馈后保持等待，不能靠旧反馈恢复运动。
- 首段直行临边则提前进入跟踪；返程临边则提前结束返程，停稳后进入向前跟踪。此时不承诺已回到初始位置，避免转弯后用等距离倒车冒充原路返回。
- 停稳阶段不外推运动趋势；阶段切换及超过 250 ms 的观测间断清除旧趋势。未确认候选不更改已确认焊道的边界包络。
- 临边实测缺失超过 500 ms、全局超过 1000 ms 才停止，推断和空图不更新时间戳。换向给予 700 ms 响应窗口，在临界 4% 内仍向外转则停止；回中 1500 ms 后临界余量继续损失超过 1% 也停止。已越过包络边界时仍有终止保护；预测进入临界区域本身只提高回中优先级。
- 巡航保持配置车体中心速度，左右轮差速改变方向；启动、返程换向和故障停止保留必要过渡。`scan_boundary_recenter` 记录回中，`scan_boundary_stop` 记录最终停止原因。

时间与余量为策略初值，尚无新版本实机稳定性结果。

## 适合分析的数据

最好提供同一 SDK 帧的原尺寸图像与轮廓：

1. 原图：设备 RAW 加格式说明/SDK 导出方法，或 SDK 原尺寸解码帧直接保存的无损 PNG。附宽、高、步长、像素格式、字节序、帧号、采集时间、曝光、增益。若相机输出 JPEG，PNG 只能防止再次压缩，不能恢复相机压缩前数据。
2. 轮廓：CSV 最便于检查，列建议为 `frame_id,timestamp,point_index,x,y,z,intensity,valid`，明确单位、无效值、坐标方向和比例，保留全部点及顺序。原始 PLY 也可，补充帧号、时间、单位并区分重复扫描与零填充。
3. 复盘：同时保留日志与任务 `raw_frames/frames.jsonl`、PNG。控制链直接消费 SDK 图像，不消费桌面缩放图；当前 SDK 轮廓只有预览路径，不参与二维闭环，不将预览抽样点当原始轮廓。
