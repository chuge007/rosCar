## 控制改变

- 用原图实际 `lineStartPx..lineEndPx` 与焊道两侧计算有效余量，坐标仍是原图像素。整图边缘不再代替激光端点。
- 独立保存实测包络、有效激光范围和接收时间。单边推断、低置信检测只能收紧包络/可用范围，不能刷新实测时间；重定位和分段不清除危险记忆。
- 余量不超过 15% 时，可靠跟踪优先向内回中，普通柔性曲率、低权重和阻尼不能取消该方向；轮端硬限制仍保留。预测以当前外移趋势和名义制动时间预留空间，只能收紧余量；回中方向与同一预测的受威胁侧保持一致，不能按另一侧的实测最近距离选错方向。
- 预计余量不超过 4%，或临边失检、推断、重定位、转向响应不可信、底盘下发目标或实际轮速仍向外转动时，立即发送双轮零命令并结束自动纠偏。临边回中 800 ms 后余量又损失超过 1% 也停止。
- 首段与返程保持直线采集合同，所以进入临边区时直接停止，不继续走满行程。相机超时检查同时覆盖返程和停稳阶段。
- 持续超过 1000 ms 没有可信实测焊道时停止，即使新图或推断持续到达。正常短暂中部失检期间仍保持目标巡航速度。
- 相机观测、轮反馈、最终发令和看门狗都经过保护。保护停止锁定到人工重新启动；后续帧不得覆盖停止原因或恢复运动。
- 原先 45%/70% 巡航降速比例已取消。自动纠偏走独立底盘命令槽：同步后恢复左右轮命令均值，按轮端上限、内轮比例和角速度限制差速，不通过整体压低轮速改变均值。启动时检查配置速度是否可实现，运行中超限命令直接故障停车。手动控制继续使用原路径。启动、停车和返程换向仍有必要过渡，实际速度仍取决于轮端响应。

停止诊断为 `event=scan_boundary_stop`，包含原因、实测/预测余量、激光范围、焊道包络、实测年龄、可信标志、回中方向、实测轮速角速度以及停止前指令；最终加速度斜坡后的指令再次通过同一保护和完整日志路径。

## 感知输入

当前默认沿母材主激光基线窄带寻找断口，以两个边缘中点定位焊道，保留原先的位置/宽度关联及三帧确认。新增的凸起轮廓提取默认关闭（`allowDisplacedContourFallback=false`），不会盖过缺口或成为启动依据。仅在调用者显式开启辅助模式时，轮廓可作为无有效缺口且未触发连续性拒绝时的低权补充，置信度上限 0.075，仍不能替换有效缺口。

检测输入保持相机 SDK 原尺寸数据，JPEG 按 SDK 分辨率解码，不经过桌面显示缩放。当前没有接入独立的、已标定三维高度 profile。
