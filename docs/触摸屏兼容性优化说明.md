## 🔧 使用示例

### 基础用法（兼容原版）

```cpp
QPushButton *button = new QPushButton("上", this);
auto *touchFilter = new JogButtonTouchFilter(button, this);
button->installEventFilter(touchFilter);

connect(touchFilter, &JogButtonTouchFilter::jogPressed,
        this, []() { robot->startMoving(Direction::Forward); });
connect(touchFilter, &JogButtonTouchFilter::jogReleased,
        this, []() { robot->stopMoving(); });
```

### 高级用法（新增功能）

```cpp
// 1. 自定义防抖参数（适合高精度触摸屏）
auto *filter = new JogButtonTouchFilter(button, this, 100, 200);

// 2. 添加长按锁定功能
connect(filter, &JogButtonTouchFilter::longPressDetected,
        this, [this](qint64 duration) {
    m_directionLocked = true;
    QMessageBox::information(this, "提示", 
        QString("方向已锁定 (按压%1秒)").arg(duration / 1000.0));
});

// 3. 实时进度显示
QProgressBar *progress = new QProgressBar(this);
progress->setMaximum(3000);
QTimer *timer = new QTimer(this);
connect(timer, &QTimer::timeout, [filter, progress]() {
    if (filter->isActive()) {
        progress->setValue(filter->currentPressDuration());
    }
});
timer->start(50);  // 20fps更新

// 4. 运行时调整灵敏度
QSettings settings;
int sensitivity = settings.value("touch_sensitivity", 150).toInt();
filter->setMinimumTouchDuration(sensitivity);
```

## 🔍 技术细节

### 状态机设计

```
[空闲] --pressed--> [激活中] --released(t≥150ms)--> [空闲]
                        |
                        +--released(t<150ms)--> [延迟等待] --timeout--> [空闲]
                        |
                        +--pressed(重复)--> [激活中] (去重，忽略)
```

### 防抖算法流程

```cpp
void onButtonPressed() {
    // 1. 停止待处理的定时器
    m_releaseTimer->stop();
    
    // 2. 检查防抖保护期
    if (m_rapidPressGuard) return;  // 300ms内拒绝
    
    // 3. 检查快速反弹
    if (timeSinceLastRelease < 50) return;  // 50ms内拒绝
    
    // 4. 检查重复激活
    if (m_gestureActive) return;  // 已激活则忽略
    
    // 5. 激活手势
    m_gestureActive = true;
    m_pressTimer.start();
    emit jogPressed();
}
```
