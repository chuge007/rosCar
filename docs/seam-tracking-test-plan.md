## 测试Case详细设计

### TC-001: 状态机基本转换

**目的**：验证从未检测到定位的完整状态链路

**步骤**：
1. 启动系统，确认初始状态为"未检测到焊道"
2. 将机器人移动到焊道附近（距离中心约50mm）
3. 观察状态变化序列
4. 记录每次状态转换的时间戳

**预期结果**：
```
t=0s:    未检测到焊道 (NotDetected)
t=1s:    本项焊道候选 (Candidate)
t=4s:    焊道已确认（校准中）(Confirmed)
t=6s:    焊道已定位 (Located)
```

**验证点**：
- [ ] 状态转换顺序正确
- [ ] 候选→确认转换需要连续3帧稳定（约3秒）
- [ ] 确认→定位转换在激光校准完成后触发
- [ ] UI显示与日志状态一致

**失败标准**：
- 状态跳步（如NotDetected直接到Located）
- 候选状态停留超过10秒
- 纠偏按钮在Located之前可点击

### TC-002: 激光中心自动校准

**目的**：验证相机坐标到激光坐标的偏移量计算

**步骤**：
1. 重置系统状态（清除历史校准）
2. 移动到焊道，等待进入Confirmed状态
3. 记录日志中的校准输出：
   - 采样的5帧raw center_x
   - 计算的平均offset
4. 进入Located状态后，记录后续帧的调整值

**预期结果**：
```
[LASER.CALIBRATION] 采样数据:
  frame 1: center_x = -1578.30 mm
  frame 2: center_x = -1579.12 mm
  frame 3: center_x = -1577.85 mm
  frame 4: center_x = -1578.64 mm
  frame 5: center_x = -1579.08 mm
  
  平均值: -1578.60 mm
  校准偏移: -1578.60 mm

[LASER.CONTROL] 定位后数据:
  raw center_x = -1579.23 mm
  laser frame x = -0.63 mm  (= -1579.23 - (-1578.60))
```

**验证点**：
- [ ] 校准使用5帧平均值（减少噪声影响）
- [ ] 转换后的laser frame x在±5mm范围内
- [ ] 校准只执行一次（重复检测不重新校准）
- [ ] UI显示校准偏移量

**失败标准**：
- 校准偏移超过±2000mm（显然异常）
- 转换后laser frame x仍接近原始值（未生效）
- 多次重复校准（每帧都校准）

### TC-003: 自适应PID - 大偏差纠正

**目的**：验证大偏差时的快速响应

**初始条件**：
- 焊道位于激光中心左侧15mm（初始误差=15mm）
- 配置：大偏差Kp=2.5, Kd=3.0

**步骤**：
1. 启动自动纠偏
2. 记录每100ms的：
   - 当前误差
   - 使用的Kp/Kd
   - 输出纠偏速度
3. 持续记录直到误差<5mm

**预期结果**：
| 时间(s) | 误差(mm) | Kp | Kd | 速度(mm/s) |
|--------|---------|----|----|-----------|
| 0.0    | 15.0    | 2.5| 3.0| 10.0      |
| 0.5    | 10.2    | 2.5| 3.0| 8.5       |
| 1.0    | 6.8     | 1.8| 2.5| 5.2       |
| 1.5    | 4.2     | 1.5| 2.0| 3.1       |
| 2.0    | 2.5     | 1.0| 1.5| 1.5       |

**验证点**：
- [ ] 初始阶段使用大偏差参数（Kp=2.5）
- [ ] 误差进入5~10mm区间时Kp自动降低
- [ ] 误差<5mm时切换到小偏差参数
- [ ] 纠偏速度限制在配置的最大值内

**失败标准**：
- 全程使用固定Kp（未自适应）
- 速度超过配置限制（安全问题）
- 出现反向加速（超调）

### TC-004: 自适应PID - 小偏差保持

**目的**：验证接近中心时的平滑保持

**初始条件**：
- 焊道已在激光中心附近（误差<2mm）
- 配置：小偏差Kp=0.5, Kd=1.0

**步骤**：
1. 手动微调机器人位置，使误差在±2mm内摆动
2. 启动纠偏，记录30秒内的误差波动
3. 计算误差均方根和最大偏离

**预期结果**：
```
误差统计（30秒采样）:
  均值(mean): -0.05 mm
  标准差(std): 0.12 mm
  最大值(max): 0.28 mm
  最小值(min): -0.32 mm
  
  RMS: 0.13 mm
```

**验证点**：
- [ ] 误差RMS < 0.2mm
- [ ] 无持续振荡（频率<1Hz的周期性摆动）
- [ ] 最大偏离 < 0.5mm
- [ ] 使用小偏差Kp/Kd参数

**失败标准**：
- RMS > 0.5mm（抖动严重）
- 出现0.5Hz以上的规律振荡
- 速度输出频繁正负翻转

### TC-005: 滤波效果验证

**目的**：验证指数滑动平均对噪声的抑制

**步骤**：
1. 配置滤波系数alpha=0.3
2. 静止状态下记录200帧：
   - raw center_x（原始检测值）
   - filtered center_x（滤波后）
3. 计算两者的标准差对比

**预期结果**：
```
无滤波时: std_raw = 0.42 mm
滤波后:   std_filtered = 0.15 mm
降噪比:   ~64%
```

**验证点**：
- [ ] 滤波后标准差明显降低（>50%）
- [ ] 滤波值变化滞后原始值约1-2帧
- [ ] 无阶跃突变（滤波平滑）

**失败标准**：
- 滤波前后标准差无显著差异
- 滤波后出现大于1mm的阶跃
- 滤波延迟过大（>5帧）

### TC-006: 焊道丢失恢复

**目的**：验证检测丢失时的状态回退和恢复

**步骤**：
1. 系统处于Located状态，纠偏运行中
2. 手动遮挡激光视野3秒（模拟焊道丢失）
3. 移除遮挡，恢复检测
4. 观察状态转换和纠偏恢复

**预期结果**：
```
t=0s:   Located，纠偏运行
t=1s:   检测丢失，状态→NotDetected
t=1.1s: 纠偏自动暂停
t=4s:   遮挡移除，检测恢复
t=5s:   状态→Candidate
t=8s:   状态→Confirmed
t=10s:  状态→Located
t=10.1s:可手动重启纠偏
```

**验证点**：
- [ ] 丢失后自动停止纠偏（不继续盲目控制）
- [ ] 恢复后需重新走完状态链路
- [ ] 不自动重启纠偏（需用户确认）
- [ ] UI正确显示丢失状态

**失败标准**：
- 丢失后继续纠偏（危险）
- 恢复后直接进入Located（跳过确认）
- 纠偏自动重启（未经用户同意）

## 测试数据分析工具

### Python分析脚本示例

```python
#!/usr/bin/env python3
"""
日志分析脚本：计算纠偏性能指标
"""

import re
import numpy as np
import matplotlib.pyplot as plt

def parse_log(log_file):
    """解析日志提取关键数据"""
    data = {
        'timestamp': [],
        'error': [],
        'kp': [],
        'kd': [],
        'speed': []
    }
    
    pattern = r'error=([\-\d.]+).*kp=([\d.]+).*kd=([\d.]+).*speed=([\-\d.]+)'
    
    with open(log_file, 'r', encoding='utf-8') as f:
        for line in f:
            match = re.search(pattern, line)
            if match:
                data['error'].append(float(match.group(1)))
                data['kp'].append(float(match.group(2)))
                data['kd'].append(float(match.group(3)))
                data['speed'].append(float(match.group(4)))
    
    return data

def calculate_metrics(data):
    """计算性能指标"""
    errors = np.array(data['error'])
    
    metrics = {
        'mean_error': np.mean(errors),
        'std_error': np.std(errors),
        'rms_error': np.sqrt(np.mean(errors**2)),
        'max_error': np.max(np.abs(errors)),
        'settling_time': None  # 到达±0.5mm的时间
    }
    
    # 计算稳定时间
    for i, e in enumerate(errors):
        if abs(e) < 0.5:
            metrics['settling_time'] = i * 0.1  # 假设100ms采样
            break
    
    return metrics

def plot_results(data, output='correction_plot.png'):
    """绘制纠偏曲线"""
    fig, axes = plt.subplots(3, 1, figsize=(12, 10))
    
    t = np.arange(len(data['error'])) * 0.1  # 时间轴
    
    # 误差曲线
    axes[0].plot(t, data['error'], label='Error')
    axes[0].axhline(y=0.5, color='r', linestyle='--', label='±0.5mm')
    axes[0].axhline(y=-0.5, color='r', linestyle='--')
    axes[0].set_ylabel('Error (mm)')
    axes[0].legend()
    axes[0].grid(True)
    
    # PID参数
    axes[1].plot(t, data['kp'], label='Kp')
    axes[1].plot(t, data['kd'], label='Kd')
    axes[1].set_ylabel('PID Gains')
    axes[1].legend()
    axes[1].grid(True)
    
    # 纠偏速度
    axes[2].plot(t, data['speed'], label='Speed')
    axes[2].set_xlabel('Time (s)')
    axes[2].set_ylabel('Speed (mm/s)')
    axes[2].legend()
    axes[2].grid(True)
    
    plt.tight_layout()
    plt.savefig(output, dpi=150)
    print(f"Plot saved to {output}")

if __name__ == '__main__':
    data = parse_log('robot_console.log')
    metrics = calculate_metrics(data)
    
    print("=== Performance Metrics ===")
    print(f"Mean Error:     {metrics['mean_error']:.3f} mm")
    print(f"Std Error:      {metrics['std_error']:.3f} mm")
    print(f"RMS Error:      {metrics['rms_error']:.3f} mm")
    print(f"Max Error:      {metrics['max_error']:.3f} mm")
    print(f"Settling Time:  {metrics['settling_time']:.2f} s")
    
    plot_results(data)
```
