## 1. 系统组成

| 程序 | 运行位置 | 作用 |
|---|---|---|
| `PA1664Workbench.exe` | 操作台 | 人机界面：超声成像、小车控制、相机与轮廓显示 |
| `PA1664RobotHost.exe` | 小车工控机 | 无界面后台服务：驱动硬件、对外提供控制与数据通道 |
| `VMS Pro.exe` | 小车工控机 | 相机调试工具：搜索相机、修改 IP |

**关键设计**：操作台不直连任何硬件。所有硬件（超声板卡、相机、激光、CAN、IMU）都接在小车主机上，操作台通过 TCP/UDP 与小车主机通信。

因此：**小车主机不在，操作台上什么都看不到。**

## 2. 网络配置

### 2.1 四张网，每张一个独立网段

| 设备 | 网卡用途 | IP | 掩码 | 网关 |
|---|---|---|---|---|
| 操作台 | 连小车 | `192.168.1.50` 或 `192.168.1.100` | `255.255.255.0` | `192.168.1.1` |
| 小车 | 主网卡（连交换机） | `192.168.1.20` | `255.255.255.0` | `192.168.1.1` |
| 小车 | 相机网卡 1 | `192.168.2.180` | `255.255.255.0` | **留空** |
| 小车 | 相机网卡 2 | `192.168.3.181` | `255.255.255.0` | **留空** |
| 车体相机 1 | — | `192.168.2.104` | `255.255.255.0` | **留空** |
| 车体相机 2 | — | `192.168.3.104` | `255.255.255.0` | **留空** |

### 2.2 三条铁律

> **① 同一台机器上，不能有两块网卡落在同一网段。**
> 否则路由表出现多条等价路由，Windows 的 ARP 会从错误网口回应，表现为「时通时不通、重启小车才恢复」。这是最常见的现场故障。

> **② 相机那两条链路（点对点直连）的网关必须留空。**
> 填了网关，相机会把回包送给网关而不是小车，表现为「能搜到设备但连不上」。

> **③ 静态地址要避开路由器的 DHCP 池。**
> 小车的 `192.168.1.20` 是静态地址。请在路由器 DHCP 设置里把 `.20` 排除（或做静态绑定），避免将来被分配给别的设备造成冲突。

### 2.3 端口

| 端口 | 协议 | 用途 |
|---|---|---|
| 43100 | TCP | 控制命令、会话握手 |
| 43101 | UDP | 实时遥测（200 ms 租约） |
| 43102 | UDP | 媒体流（相机、点云、超声帧） |
| 43103 | TCP | 批量通道（扫描批次、录像） |

小车端必须放行上述端口的**入站**。若 Windows 防火墙处于开启状态（专用/公用网络），需手工添加规则；现场机器通常将专用网络的防火墙关闭。

## 3. 车端（小车）配置

### 3.1 目录结构

整包部署到 `C:\Users\a\Desktop\robot_host\`：

```
app\                        PA1664RobotHost.exe + Qt DLL + ultrasound_device.dll
app\config\drive_settings.ini   设备配置（电机/相机/激光/夹爪）
app\default_config.json     超声默认参数
app\parameter_presets.json  超声参数预设
config\host.psd1            监听配置
StartRobotHost.cmd          启动入口（双击）
StartRobotHost.ps1          启动脚本（读 host.psd1）
InstallAutoStart.ps1        安装开机自启
runtime\launcher.log        启动日志
app\logs\robot_host.log     运行日志
```

### 3.2 `config\host.psd1`

```powershell
@{
    ListenAddress = '0.0.0.0'
    ControlPort   = 43100
    RealtimePort  = 43101
    MediaPort     = 43102
    BulkPort      = 43103
}
```

四个端口必须互不相同。

### 3.3 `app\config\drive_settings.ini` 关键项

| 配置项 | 现场值 |
|---|---|
| `networkCameraUrl0` | `rtsp://192.168.3.104:554/user=admin&password=&channel=1&stream=0.sdp?real_stream` |
| `networkCameraUrl1` | `rtsp://192.168.2.104:554/user=admin&password=&channel=1&stream=0.sdp?real_stream` |
| `wheelCommunicationMode` | `can` |
| `wheelCanSerialPort` / `wheelCanBitrate` | `COM8` / `1000000` |
| `leftMotorId` / `rightMotorId` | `1` / `2` |
| `rightMotorSign` | `-1` |
| 夹爪 X 轴（2 台 MWD） | `pcan:51`，`canBitrate=1000000` |
| 夹爪 Z 轴（2 台 ZDT） | `candle:...`，`canBitrate=500000` |
| `imuSerialPort` / `imuBaudRate` | `COM3` / `9600` |
| `laserSerialNumber` | `DB2666828` |

**修改前先备份**：`copy drive_settings.ini drive_settings.ini.bak_日期`

### 3.4 开机自启

管理员 PowerShell 运行一次：

```powershell
powershell -ExecutionPolicy Bypass -File C:\Users\a\Desktop\robot_host\InstallAutoStart.ps1
```

会在「启动文件夹」和桌面各建一个快捷方式，登录后自动拉起小车主机。

### 3.5 车端节能设置（必须做）

| 项 | 设置 |
|---|---|
| 电源计划 | 禁止睡眠 / 休眠 / 关闭硬盘 |
| 网卡「允许计算机关闭此设备以节约电源」 | 取消勾选（每块网卡） |
| Wake on Magic Packet / Pattern / Link Change | 全部 Disabled |
| USB 选择性挂起 | 禁用（交流 + 电池） |

未关闭时典型现象：闲置十几分钟后远程失联，必须重启才恢复。

## 4. 操作台配置

### 4.1 程序部署

**整目录**拷贝 `bin\`（含 Qt、OpenCV 等 DLL），不要只拷 exe。

### 4.2 连接地址

首次启动显式指定小车地址：

```
PA1664Workbench.exe --remote 192.168.1.20:43100
```

程序会把地址写入注册表，之后直接双击即可：

```
HKCU\Software\PA1664\PA1664Workbench\remote\endpoint = 192.168.1.20:43100
```

也提供两个启动脚本（仓库根目录）：

| 脚本 | 用途 |
|---|---|
| `start_workbench_robot.bat` | 连小车 `192.168.1.20:43100`（日常使用） |
| `start_workbench_localhost.bat` | 连本机 `127.0.0.1`（本机联调 Host 时用） |

### 4.3 单实例保护

同一台操作机只允许开一个 Workbench。第二个实例会弹提示后退出（退出码 3）。

原因：小车主机只接受**一个**控制会话，同时开多个会互相抢占，表现都是「连上了但没有任何数据」。

### 4.4 操作台节能设置

与车端相同：关闭 USB 选择性挂起、关闭网卡三项唤醒。

若操作台用 USB 转网口，务必**直插机身后置 USB 口**，不要经过 USB HUB——HUB 供电不稳会导致网卡整个从系统消失。

## 5. 外部设备

| 设备 | 接口 | 要点 |
|---|---|---|
| 超声板卡 | USB | 需安装 CYUSB3 驱动，设备管理器能识别 |
| 车体相机 ×2 | 分别接小车两块相机网卡 | 雄迈（XMEye）方案，用 `VMS Pro` 改 IP |
| 激光轮廓仪 | USB | 序列号须与 `laserSerialNumber` 一致 |
| 轮电机 | CAN（COM8） | 1000000 bps |
| 夹爪 X 轴 | PCAN | `pcan:51` |
| 夹爪 Z 轴 | candleLight USB-CAN | 500000 bps |
| IMU | COM3 | 9600 bps |

### 5.1 用 VMS Pro 修改相机 IP

1. 在小车上打开 `C:\Program Files\VMS Pro\VMS Pro.exe`
2. 进入「设备管理 / 设备列表」→「搜索设备」
3. 选中相机 → 右键「修改 IP / 网络配置」
4. 填写 IP、掩码 `255.255.255.0`、**网关留空** → 保存

注意事项：

- 接在小车「相机网卡 1」的相机必须是 `192.168.2.x`
- 接在「相机网卡 2」的必须是 `192.168.3.x`
- **不要再改回 `192.168.1.x`**，否则又变成多网卡同网段
- 改完同步更新 `drive_settings.ini` 里对应的 `networkCameraUrlN`，然后重启小车主机

相机恢复出厂后默认地址通常为 `192.168.1.108`，此时需先能访问它才能改 IP。

## 6. 日常操作流程

### 6.1 启动顺序

```
① 小车：确认通电 → 双击 StartRobotHost.cmd（或等开机自启）
② 操作台：双击 start_workbench_robot.bat
③ 观察状态栏变为「● 主机在线 192.168.1.20:43100 / SDK 已连接」
④ 观察「● USB 硬件在线」
```

### 6.2 超声采集

1. 连接 SDK：点击「连接 SDK」（已连接时显示「断开 SDK」）
2. 开始采集：点击采集开关，状态栏显示「硬件在线，正在采集」
3. 扫描缓存：右侧操作栏「启动」→ 自动开启 B 扫与编码器路径记录
   - 「暂停」：暂停缓存写入，实时 A 扫继续
   - 「停止」：结束本次扫描缓存，已采图像保留
4. 视图：超声检测页可切换 A / B / C / E 扫，双击图谱「复位视图」

### 6.3 小车控制

切到「小车控制」页签：

- 手动运动：按住方向键移动，松开即停；按住超过 3 秒进入锁定
- 使能/急停：先使能才能运动，任何时候急停优先
- 轮廓显示：X/Z 实时轮廓与「本帧焊道候选」指示
- 自动纠偏：按页面上的启动/停止控制

### 6.4 关闭顺序

```
① 操作台：先「停止」扫描缓存 → 关闭 Workbench
② 小车：关闭 PA1664RobotHost（可选，无常驻需求时）
```

关闭操作台会让小车端自动停止纠偏与外设，这是正常保护行为。

## 7. 界面状态判读

状态栏三个指示灯是最快的判断入口：

| 显示 | 含义 |
|---|---|
| `● 主机在线 <IP>:43100 / SDK 已连接` | 操作台 ↔ 小车主机链路正常，SDK 已连 |
| `● 等待小车主机 <IP>:43100` | 主机可达但未完成握手，或主机未启动 |
| `● 网络不通 <IP>:43100（本机无同网段地址）` | 本机没有该网段 IP，物理链路断了（网线/网卡问题） |
| `● USB 硬件在线` | 超声板卡在线 |
| `● SDK 初始化中` | 板卡已连，配置尚未下发完 |
| `● 开始已排队` | 已下发开始命令，等待板卡响应 |
| `● 硬件未确认` | 板卡无响应，检查 USB 连接与供电 |
| `参数预设 N \| 硬件组 0 \| 丢弃 M` | 当前软件预设、硬件工作组、丢包计数 |

## 8. 故障排查

### 8.1 第一步：跑一键自检

**操作台根目录双击 `check_link.bat`**，六项依次判读：

| 项 | 检查内容 |
|---|---|
| [1] | 本机 IPv4 地址列表 |
| [2] | 本机是否存在与 `192.168.1.20` 同网段的地址 |
| [3] | ping 小车 |
| [4] | 43100 端口可达性 |
| [5] | 小车端 `PA1664RobotHost` 进程 |
| [6] | 本机运行的 Workbench 实例数（只允许 1 个） |

判读表：

| 现象 | 结论 | 处理 |
|---|---|---|
| [2] NG | 物理链路断开 | 检查网线、USB 网卡是否插好、网卡是否被禁用 |
| [2][3] OK，[4] NG | 小车主机未启动 | 在小车上双击 `StartRobotHost.cmd` |
| [6] > 1 | 多个操作台抢会话 | 只保留一个窗口 |
| [4] OK 但仍无数据 | 会话或外设问题 | 查日志关键字 `not_session_owner` |

### 8.2 日志位置

| 位置 | 内容 |
|---|---|
| 操作台 `bin\logs\robot_console.log` | 操作台全部日志（链路、媒体接收、参数操作） |
| 操作台 `bin\logs\errors.log` | 只记错误 |
| 操作台 `bin\logs\comm\*.log` | 通信分类日志 |
| 小车 `app\logs\robot_host.log` | 主机日志（超声采集、CAN、外设） |
| 小车 `runtime\launcher.log` | 启动器日志（启动失败先看这里） |
| 小车 `app\logs\comm\*.log` | 通信分类日志 |

**注意**：超声没有独立日志文件，超声状态只能从 `robot_console.log` / `robot_host.log` 的内容里找（关键词 `ULTRASOUND`、`SCAN_INGEST_TELEMETRY`、`SCAN_DECODER_TELEMETRY`）。

### 8.3 常见故障对照表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 状态栏「网络不通」 | 网线松 / USB 网卡掉线 / 网卡禁用 | 查 `check_link.bat` 第 [2] 项；USB 网卡换后置口 |
| 「等待小车主机」一直转 | 小车 Host 未启动；或 IP 配错 | 看小车 `launcher.log`；核对 `endpoint` 注册表值 |
| 连上了但全部空白 | 另一个操作台占着会话 | 关闭多余实例，重启操作台 |
| 时通时不通、重启才好 | 小车多块网卡同网段 | 按第 2 章拆成独立网段 |
| 相机无图像 | 相机 IP 与网段不匹配 / 网关填了 | 用 VMS Pro 核对 IP，网关清空 |
| 超声帧数为 0 | 板卡未识别 / USB 异常 | 查小车日志 `ULTRASOUND`，重新插拔板卡 |
| 点云无数据 | 激光轮廓仪 USB 未识别 | 查 `laserSerialNumber` 与设备是否一致 |
| 扫描缓存「启动」无反应 | 未开始采集 | 先点采集开关，再启动缓存 |
| 操作台闲置后失联 | 网卡节能 / 系统休眠 | 按 3.5 / 4.4 关闭节能 |

### 8.4 小车端程序卡死

操作台右侧「小车端程序」分组里有 **「重启小车端程序」** 按钮，走独立运维端口，主机主线程被驱动调用堵死时仍可用。

若该按钮也无效，在小车上执行：

```
taskkill /F /IM PA1664RobotHost.exe
del /Q C:\Users\a\Desktop\robot_host\app\robot_host.lock
双击 StartRobotHost.cmd
```

### 9.1 关键路径

### 9.2 常用远程命令（小车）

```cmd
ssh a@192.168.66.10
tasklist | findstr PA1664RobotHost
netstat -ano | findstr :43100
type C:\Users\a\Desktop\robot_host\runtime\launcher.log
```

远程原生命令输出为 GBK，需前置 `chcp 65001 >nul` 才能正确显示中文。

### 9.3 术语

| 术语 | 含义 |
|---|---|
| 主机 / Host | 小车端的 `PA1664RobotHost` 后台服务 |
| 会话（session） | 一次操作台登录小车主机的连接，同一时刻只允许一个 |
| 控制会话所有权 | 只有持有会话的操作台能下发控制命令，其他会被拒绝（`not_session_owner`） |
| 扫描缓存 | 按编码器行程保存 B 扫/C 扫数据的机制 |
| 硬件组 | 板卡侧的工作组，通常固定为 0 |
| 参数预设 | 软件侧的参数集合，可与硬件组解耦 |
