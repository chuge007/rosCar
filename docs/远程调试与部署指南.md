# 远程调试与部署指南（SSH 直连小车端）

> 适用场景：开发机（上位机开发环境）直接通过 SSH 访问小车端电脑，用于**查看日志**和**替换 PA1664RobotHost.exe**。
>
> 最后更新：2026-11-09

---

## 1. 连接信息

| 项目 | 值 |
|------|-----|
| 小车端 IP | `192.168.1.20` |
| 用户名 | `a`（属于 Administrators 组） |
| 主机名 | `DESKTOP-3AQ3FDU` |
| 认证方式 | **SSH 公钥免密**（已配置，无需密码） |
| 小车端部署目录 | `C:\Users\a\Desktop\robot_host` |

### 免密登录原理（重装系统后需重做）

小车端账户 `a` 在 Administrators 组，Windows OpenSSH 对管理员组**不读** `~\.ssh\authorized_keys`，只读系统级文件。必须在小车端**以管理员身份**打开 PowerShell 执行：

```powershell
# 1. 写入公钥（开发机 ~/.ssh/id_ed25519.pub 的内容）
Add-Content -Encoding ascii 'C:\ProgramData\ssh\administrators_authorized_keys' 'ssh-ed25519 AAAA...开发机公钥...'
# 2. 修正文件权限（Windows sshd 要求只允许 SYSTEM / Administrators 访问）
icacls 'C:\ProgramData\ssh\administrators_authorized_keys' /inheritance:r /grant 'SYSTEM:(F)' /grant 'Administrators:(F)'
# 3. 重启服务
Restart-Service sshd
```

> 注：Windows 账户即使**无登录密码**，sshd 默认也不允许空密码登录（`PermitEmptyPasswords`），所以必须用公钥方式。

## 2. 常用 SSH 命令

```powershell
# 交互式登录小车端
ssh a@192.168.1.20

# 远程执行单条命令
ssh a@192.168.1.20 "命令"

# 上传文件到小车端
scp 本地文件 a@192.168.1.20:C:/Users/a/Desktop/robot_host/app/

# 从小车端下载目录到本地
scp -r a@192.168.1.20:C:/Users/a/Desktop/robot_host/app/logs .
```

### 中文乱码处理

小车端是中文 Windows，SSH 远程执行 `dir` 等命令会输出 GBK 编码，开发机显示为乱码。远程命令前加 `chcp 65001` 可切到 UTF-8：

```powershell
ssh a@192.168.1.20 "chcp 65001 >nul && dir C:\Users\a\Desktop\robot_host\app\logs"
```

## 4. 日志位置

### 小车端（远程，实时真实数据）

| 路径 | 内容 |
|------|------|
| `C:\Users\a\Desktop\robot_host\app\logs\robot_host.log` | 主运行日志（最大、最全） |
| `C:\Users\a\Desktop\robot_host\app\logs\robot_console.log` | 控制台日志 |
| `C:\Users\a\Desktop\robot_host\app\logs\camera_connection.log` | 相机连接日志 |
| `C:\Users\a\Desktop\robot_host\app\logs\log_YYYYMMDD_HHMMSS.txt` | 按启动时间归档的日志 |
| `C:\Users\a\Desktop\robot_host\app\Mv3dLpLog\Mv3dLp_00.log` | 激光轮廓仪 SDK 日志 |
| `C:\Users\a\Desktop\robot_host\app\RobotControl\logs\robot_console.log` | 底盘、IMU、相机详细日志 |

### 本地（开发机）

| 路径 | 内容 |
|------|------|
| `bin\logs\robot_console.log` | 本地运行控制台日志 |
| `bin\logs\camera_connection.log` | 本地相机连接日志 |
| `bin\logs\comm\` | 通信日志 |
| `bin\RobotControl\logs\robot_console.log` | 本地控制模块日志 |
| `bin\Mv3dLpLog\Mv3dLp_00.log` | 本地激光 SDK 日志 |
| `startup_deploy\robot_host\app\logs\` | 部署包运行日志（拷过去后才产生） |
| `startup_deploy\operator_workbench\app\logs\robot_console.log` | 操作端日志 |

日志格式：`时间戳 #序号 [线程ID] [级别] [模块] event=事件 详细信息`

### 查看日志的常用命令

```powershell
# 远程查看最后 100 行
ssh a@192.168.1.20 "chcp 65001 >nul && powershell -Command \"Get-Content 'C:\Users\a\Desktop\robot_host\app\logs\robot_host.log' -Tail 100\""

# 远程搜索关键字（纠偏、错误、连接失败等）
ssh a@192.168.1.20 "chcp 65001 >nul && findstr /i /c:\"CORRECTION\" /c:\"ERROR\" C:\Users\a\Desktop\robot_host\app\logs\robot_host.log"

# 把远程日志拉到本地分析（推荐，避免编码问题）
scp a@192.168.1.20:C:/Users/a/Desktop/robot_host/app/logs/robot_host.log d:\dev\deskCrawlingRobot\CrawlingRobotSV\PA1664WorkbenchTmpSeparate\tmp\

# 本地查看最后 200 行
Get-Content 'd:\dev\deskCrawlingRobot\CrawlingRobotSV\PA1664WorkbenchTmpSeparate\bin\logs\robot_console.log' -Tail 200
```

## 5. 更新小车端 EXE（标准流程）

### 5.1 编译（开发机）

按项目规则编译，输出目录为 `bin\`：

```powershell
# 方式一：命令行（需 VS 2022 原生工具环境）
cd d:\dev\deskCrawlingRobot\CrawlingRobotSV\PA1664WorkbenchTmpSeparate
.\build_host.bat

# 方式二：部署脚本（含打包）
cd startup_deploy
.\build-all.ps1 -QuickMode          # 仅更新 EXE（日常改代码）
.\build-all.ps1                     # 完整构建（依赖变化时）
```

产物：`bin\PA1664RobotHost.exe`（或 `startup_deploy\robot_host\app\PA1664RobotHost.exe`）。

### 5.2 停止小车端程序

替换前必须先停程序，否则文件被占用会失败：

```powershell
ssh a@192.168.1.20 "chcp 65001 >nul && taskkill /F /IM PA1664RobotHost.exe & del C:\Users\a\Desktop\robot_host\app\robot_host.lock"
```

（如果程序是随开机自启的，替换完成后再重新启动。）

### 5.3 备份旧 EXE

```powershell
ssh a@192.168.1.20 "chcp 65001 >nul && copy /Y C:\Users\a\Desktop\robot_host\app\PA1664RobotHost.exe C:\Users\a\Desktop\robot_host\app\PA1664RobotHost.exe.bak"
```

### 5.4 上传新 EXE

```powershell
cd d:\dev\deskCrawlingRobot\CrawlingRobotSV\PA1664WorkbenchTmpSeparate
scp bin\PA1664RobotHost.exe a@192.168.1.20:C:/Users/a/Desktop/robot_host/app/PA1664RobotHost.exe
```

### 5.5 校验并启动

```powershell
# 校验大小/时间戳
ssh a@192.168.1.20 "chcp 65001 >nul && dir C:\Users\a\Desktop\robot_host\app\PA1664RobotHost.exe"

# 启动程序（在会话 0 之外启动 GUI/后台服务，建议用启动脚本）
ssh a@192.168.1.20 "chcp 65001 >nul && cd /d C:\Users\a\Desktop\robot_host && StartRobotHost.cmd"
```

### 5.6 验证

```powershell
# 确认进程起来了
ssh a@192.168.1.20 "chcp 65001 >nul && tasklist | findstr PA1664RobotHost"

# 看启动日志有没有 ERROR
ssh a@192.168.1.20 "chcp 65001 >nul && powershell -Command \"Get-Content 'C:\Users\a\Desktop\robot_host\app\logs\robot_host.log' -Tail 60\""
```

## 6. 注意事项

1. **编译必须用项目规定的工具链**（Qt 6.8.x + MSVC 2022 64 位），`compile_commands.json` 由 `gen_compile_commands.bat` 维护，供 clangd 使用。
2. **只替换 EXE 时**必须是同一套 Qt/DLL 版本编译出来的，否则会出现缺 DLL 或插件加载失败。DLL 版本变化时必须走完整构建并整目录覆盖。
3. 替换 EXE 后如果程序起不来，先用备份 `PA1664RobotHost.exe.bak*` 回滚，再对比日志。
4. 远程 `dir`、`findstr` 等原生命令输出为 GBK，建议统一加 `chcp 65001`，或改用 `scp` 拉回本地分析。
5. `app\robot_host.lock` 是运行中标记，程序异常退出时可能残留，需要手动 `del` 后再启动。
6. 所有远程操作**只允许改动** `C:\Users\a\Desktop\robot_host` 下的文件，不要动小车端其他目录和系统配置。
