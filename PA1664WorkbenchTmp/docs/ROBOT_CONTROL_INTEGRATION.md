# 小车运动控制集成说明

## 使用方法

1. 启动 `bin\PA1664Workbench.exe`。
2. 点击主窗口的“**小车控制**”页签，或者使用菜单“**工具 -> 切换到小车运动控制**”（快捷键 `Ctrl+Shift+M`）。
3. 在右侧“底盘接口与参数”确认左右轮串口、波特率、ID、方向、轮径、轮距和安全超时。
4. 在右侧“手动调节”依次连接底盘、使能底盘，再按住方向按钮点动；松开按钮立即发送零速命令。
5. 紧急情况下点击红色“紧急停止”。
6. 菜单“**信息 -> 小车信息**”会打开独立小窗，左侧为小车状态，右侧为小车日志。
7. 夹具 X/Y/Z 点动位于“小车控制”页底部、紧急停止下方；使用水平滑块控制方向和速度，松开后自动回中，也可在“**超声检测 -> 探头调节**”中使用原有点动控制。
8. 激光自动纠偏参数位于“小车配置”，自动纠偏的启动、停止和状态位于“小车控制”。

超声采集与小车运动目前分别启停，可以按现场任务需要独立组合，整个操作过程只有一个产品主窗口。

## 架构边界

- 双轮控制、差速混合、同步控制、MWD RS485 协议、反馈看门狗和安全状态机直接编译进 Qt 6 工作台，并运行在专用控制线程。
- 夹持机构控制位于超声右侧“探头调节”页签，现场参数写入 `bin\config\drive_settings.ini`。
- 主程序退出时先向底盘下发急停，再执行控制器安全关闭并释放串口。
- 小车控制核心已复制到本工程 `src\robot`；原项目不再参与编译，也没有被修改。
- LanRemoteQt 控制被控端桌面，因此远端操作员只需要操作同一个 PA-1664 产品窗口。
- USB 相机已经由 Qt Multimedia 在小车页内直接采集和预览。MV3DLP 激光轮廓与自动纠偏仍待迁移，原因是当前工程缺少 `mv3dlp_laser_profile` 开发源组件；左上轮廓区已预留图像接口，不会暗中启动旧版窗口。

## 夹子电机 MWD CAN / PCAN

在每台夹子电机的配置中选择“MWD CAN”，端口选择实际枚举出的 `PCAN_USBBUS1` 等通道，填写电机 ID 和 CAN 总线波特率，保存后连接。PCAN 使用原生 PCAN-Basic 接口，不需要串口号或串口波特率；共用一个 PCAN 通道的电机必须使用相同 CAN 波特率及不同 ID。未插入适配器时也可输入 `PCAN_USBBUS1` 预先配置，刷新时会保留选择并标注未连接。

Windows 需安装 PEAK-System 驱动及与程序位数一致的 `PCANBasic.dll`。程序动态加载程序目录或 Windows 系统目录的 DLL，不需要额外链接 SDK，也不要将厂家 32 位调试软件的 DLL 复制到 64 位程序目录。通道占用、初始化及发送/接收故障会报告 PCAN 错误；运行中故障会尝试停止所有已连接夹子电机、复位滑块并要求重新连接。总线断开时停止指令可能无法送达，界面不会将发送成功当成电机应答。

工程内 `MWD--MCF302CB` 是 STM32 例程，使用标准经典 CAN 帧、ID `0x140 + 电机ID`、8 字节数据，例程波特率为 **1 Mbit/s**。实际配置须与电机一致。例程的 `0xA7` 为位置指令；本程序夹子滑块继续使用速度指令 `0xA2`，松开发送 `0x81` 停止。PCAN-FD 型号可用经典 CAN 模式连接，不发送 CAN FD 帧。PCAN 接入限于夹子电机，底盘 CAN 配置仍使用现有 SLCAN 接口。

## 发布

编译需要 Qt 6.8.3 Serial Port 模块。`deploy-runtime.ps1` 会部署 `Qt6SerialPort.dll`，并在首次发布时从本工程 `runtime\config\drive_settings.ini` 初始化现场参数；重新编译不会覆盖已校准的 `bin\config\drive_settings.ini`。

## 后续自动联动

若要实现“开始 B/C/E 扫时自动驱动小车、到位后自动停止并关联位置”，下一步应在同一主程序中增加自动扫查任务层。任务层只组合现有的超声控制器与运动控制器，必须保持小车安全状态机对急停、通信超时、限速和故障停车拥有最终裁决权。
