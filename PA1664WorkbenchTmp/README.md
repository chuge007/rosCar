# PA1664WorkbenchTmp

Qt 6 PA1664 超声与爬壁机器人工作台。此目录保存已合并的完整工程源码；仓库根目录的原有机器人项目保留。

本次同步 PA1664WorkbenchSV 的超声设备控制、帧解码、参数预设、扫描波形缓存、脉冲负载保护和远程控制功能。机器人界面、控制算法、夹持、摄像头、传感器和激光算法保留目标工程实现；仅在自动纠偏入口对接现有使能流程，让未使能或停止状态可以点击纠偏启动，故障与急停保护继续生效。

## 工程与依赖

工程入口为 `PA1664Workbench.pro`，使用 Qt 6、MSVC x64 和 OpenCV。`opencv.pri` 支持设置 `OPENCV_ROOT` 与 `OPENCV_VERSION_SUFFIX`。

提交包含 SDK 接口头文件和激光驱动源码，不包含 SDK 二进制、运行配置、生成文件或设备日志。使用前需要本地提供 `vendor/phaselink/lib/client.lib`、对应 SDK 运行文件以及激光设备运行依赖。`build.cmd` 与 `deploy-runtime.ps1` 保留原有本机路径，使用时按环境配置。

已对本次修改的 12 个 C++ 文件完成 MSVC `/Zs` 语法检查，并核对机器人源码保留范围和发布副本 SHA256；未运行 Qt 编译、链接或完整构建。设备采集和纠偏行为需要连接硬件验证。
