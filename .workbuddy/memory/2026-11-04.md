## 项目架构通读结论（代码级）

**三个构建目标（三个 .pro）**
- `PA1664Workbench.pro` → GUI 客户端（主控台），两页 QTabWidget：`超声检测` / `小车控制`（mainwindow.cpp:882/898）。
- `PA1664CameraServer.pro` → 无 GUI 相机服务，仅 camera_server_main/camera_server，推流给 Workbench。
- `PA1664RobotHost.pro` → 无 GUI 常驻主机，`backend/main.cpp` + HostApplication，独占硬件句柄。注意 .pro 里 `CONFIG += no_batch` 是防 src/main.cpp 与 src/backend/main.cpp 同名被 MSVC 批处理误编。

**传输层（src/common）**：4 条通道，端口 43100 control / 43101 realtime(UDP) / 43102 media / 43103 bulk；magic 0x50413136("PA16")，版本 1；control 帧头 50B、上限 1MiB；media 帧头 58B + HMAC 16B 分片；bulk 帧头 28B。握手协商 capability 字符串（robot.control.v1 / ultrasound.bulk.v1 等），UI 必须按 capability 门控。

**Host 侧三个服务（HostApplication 组装）**
- UltrasoundHostService：独占超声 SDK + DeviceController，跑在独立 QThread。
- RobotHostService：底盘运动、会话占有（ownerSessionId）、运动租约 200ms/心跳 250ms/会话超时 1000ms。
- RobotPeripheralHostService：**内部持有 LaserCorrectionController** + RobotSensorController + ClampMotorController + RobotUsbCameraController；`driveCorrectionCommand` → RobotHostService::setCorrectionCommand（host_application.cpp:191）。

**双模式**：`--local`/测试参数 → Workbench 进程内直接持有 DeviceController 与 SynchronizedDriveController；默认走 remote，`--remote host:43100` 或 `PA1664_REMOTE_HOST` 或 QSettings remote/endpoint。远程模式下 RobotControlPanel **仍然在 UI 进程内跑一份 LaserCorrectionController**（robotcontrolpanel.cpp:408-413 直连），Host 侧也有一份——改纠偏代码要注意两处布局。

**超声链路**：SDK(Client) → DeviceController(RawPacket) → PacketDecoder(DecodedFrame) → FrameDecoderWorker(线程) → MainWindow → A/E/B/C ScanWidget + ScanWaveformCache；多 group（groupOffsetWords），编码器换算 `m_encoderMmPerCount = π*500/4096`。

**激光链路**：MV3DLP 点云 → RobotSensorController::correctionProfileFrameReady（DirectConnection）→ LaserCorrectionController::submitProfileFrame（邮箱式，只保留最新帧）→ 定位（默认 SIMPLE 算法，可选 ORIGINAL/ENHANCED）→ 段内最小二乘直线拟合（sampleSpacing 4mm、segmentLength 30mm、min 8 点、RMS≤15mm）→ PD(3.0/0.12, α0.18) + 激光居中反馈(0.60, lookahead 0.25m) + 曲率限幅 1.5 rad/m、maxAngular 0.25 rad/s → 差速。

**超时参数（当前代码实际值）**：imageTimeoutMs 500、telemetry 600、detection 500、transientHold 500、detectionRecovery 1800、motionStall 8000。**本版本没有 LASER_LOST 字面量**——之前记忆里的"激光丢失≥2s 停止"不属于这个仓库，不要混用。

**关键源文件规模**：laser_correction_controller.cpp 4600+ 行，是最大单文件，改动前务必先跑 impact。
